05 — FINDING A RESOURCE

Every web address has a story.

A URL identifies the location of a resource on the Web. A domain name provides a human-readable name for a website.

https://www.example.com/products
https:// Protocol

Indicates the communication protocol used to access the resource.

www.example.com Domain name

/products Path

Identifies a particular resource or location within the website.
